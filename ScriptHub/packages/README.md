# `packages/`

This folder contains externally imported libraries, such as **_GoodSignal_**, **_Fusion_**, **_Roact_**, etc.

> In most non-Luau projects, external packages are typically managed automatically by a package manager.  
> However, the only major package manager for Roblox is **[Wally](https://github.com/UpliftGames/wally)**, which **only works in Roblox environments** because it relies on instance-based indexing instead of filesystem-based paths.  
>
> Due to this, the only viable option (for now) is to **manually import packages**.

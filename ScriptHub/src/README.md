# `src/`

> Also known as “source”. </br> This folder contains all of your project's code.

Everything in this directory should authored and maintained by you. Packages should live elsewhere (e.g., `packages/` or `lib/`).

## main.luau

> Also known as "init.luau"

This is the **entry point** for the bundler/compiler. It is the root of your project and is typically responsible for bootstrapping initialization logic or exporting your main API.

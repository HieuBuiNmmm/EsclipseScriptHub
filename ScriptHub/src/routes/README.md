# `routes/`

This folder should include context-specific entry points (routes). In the case of a script-hub, this would be where you place routes for different games.

Default routes

- `base.luau` (Base route, this helps reduce boilerplate code when routes inherit its logic.)
- Game 1
  - `main.luau` (Entry point for this route.)
- Game 2
  - `main.luau`
- Universal
  - `main.luau`
